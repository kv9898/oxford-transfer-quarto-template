# Change Log

All notable changes to the `oxford-transfer` Quarto extension will be documented
in this file.

## v1.1.0

- Add a Quarto Wizard v2 schema for format-option completion, hover
  documentation, and diagnostics.
- Add namespaced snippets for document metadata, layout options, and the
  optional crest.
- Nest custom title-page metadata under `format: oxford-transfer-pdf:` in the
  example and documentation so it is discoverable through the format schema.

## v1.0.0

- Convert the Oxford Transfer of Status LaTeX template to a Quarto PDF format.
- Add configurable title-page metadata, running headers, and footer styles.
- Add Quarto-managed contents, figure, table, listing, abstract, and appendix pages.
- Make the Oxford crest an optional, user-supplied local asset.
